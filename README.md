# 원더리벳 2026 콜 연습

WONDERLIVET 2026(2026-11-20~22, 고양 킨텍스) 출연 팀의 곡을 YouTube로 틀어 놓고 가사·한글 발음·콜을 시간에 맞춰 따라 하는 개인 연습 사이트입니다. 빌드 과정 없는 정적 사이트(HTML + ES 모듈 + JSON)이고 GitHub Pages로 배포합니다.

## 로컬 실행

정적 파일 서버로 저장소 루트를 띄웁니다.

```sh
npx serve .
# 또는
python3 -m http.server 8000
```

`index.html`을 `file://`로 직접 열면 동작하지 않습니다. ES 모듈과 `fetch`가 막히고, YouTube 임베드도 재생되지 않습니다.

주소는 `http://localhost:<포트>`로 여세요. `http://127.0.0.1:<포트>`로 열면 레이블이 걸린 공식 음원·MV 다수가 오류 150(임베드 불가)으로 재생되지 않습니다. GitHub Pages 같은 공개 HTTPS 주소에서는 정상 재생됩니다.

## 화면

| 주소 | 화면 |
|---|---|
| `#/` | 일자별 아티스트 목록 |
| `#/artist/<artist-id>` | 아티스트의 공연 의식과 곡 목록 |
| `#/song/<song-id>` | 연습 화면 |
| `#/edit/<song-id>` | 타이밍 보정 도구 |

## 데이터 구조

```
data/
├─ lineup.json                       # 아티스트: 일자·스테이지·시간·공연 의식
└─ songs/
   ├─ index.json                     # npm run validate가 생성 (직접 고치지 않음)
   └─ <artist-id>/<song-id>.json     # 곡 하나
```

곡 파일의 콜(`cues[]`)은 `at`으로 시간을 정합니다.

| `at` | 의미 |
|---|---|
| `{ "line": 12, "offset": 0.4 }` | `lines[12]`(0부터 세므로 13번째 줄) 시간 + 0.4초 |
| `{ "t": 83.2 }` | 가사 시간 83.2초 (간주·인트로처럼 가사가 없는 구간) |
| `{ "t": null, "afterLine": 13 }` | 시간 미정. 보정 도구로 찍는다. `afterLine`(선택)은 목록에서 `lines[13]` 뒤에 표시하라는 뜻 |

- `line`은 **0 기준 첨자**입니다. 자료에 "N번째 줄"이라고 적혀 있으면 `N - 1`로 적습니다. 한 줄 밀린 값은 형식상 유효해서 검증으로 잡히지 않습니다.
- `cues[]`는 곡 순서대로 적습니다. 시간 미정 콜은 `afterLine`이 없으면 목록에서 바로 앞 콜과 같은 자리에 표시되므로, 간주·인트로 콜에는 `afterLine`을 적습니다(인트로는 `-1`).
- 콜 종류(`type`): `call`(외치기), `clap`(박수), `jump`(점프), `singalong`(떼창), `motion`(손동작), `penlight`(펜라이트, `color` 필요), `other`
- 영상 시간 = 가사 시간 + `youtube.offsetSec`
- 한국어 곡은 `lines[].ko`를 `null`로 두고 `review.pronunciation`을 `true`로 둡니다.
- 아티스트 화면의 곡 순서는 선택 필드 `order`(숫자)로 정합니다.

## 곡 추가 절차

1. **영상 고르기.** "Provided to YouTube" 공식 음원(Topic 채널)을 먼저 고르고, 없으면 공식 MV를 씁니다. 라이브 영상은 쓰지 않습니다.
   ```sh
   node tools/yt-search.mjs "THE ORAL CIGARETTES 狂乱 Hey Kids" 5
   ```
   `embed O`는 oEmbed 확인 결과일 뿐이니 연습 화면에서 직접 재생해 보세요. 이때 `127.0.0.1`이 아니라 `localhost`로 열어야 정확합니다(위 "로컬 실행" 참고).
2. **뼈대 만들기.** LRCLIB에서 동기화 가사를 받아 곡 파일을 만듭니다. 이미 있는 파일은 덮어쓰지 않습니다.
   ```sh
   node tools/fetch-lrclib.mjs "THE ORAL CIGARETTES" "狂乱 Hey Kids!!" 251 \
     --id oral-kyouran-hey-kids --video <videoId>
   ```
   - 아티스트는 `lineup.json`의 `name` 또는 `lrclibName`으로 찾습니다. 못 찾으면 `--artist-id`를 줍니다.
   - 동기화 가사가 없으면 `t: null`인 줄로 뼈대를 만듭니다. 이때는 보정 도구로 줄 시간을 모두 찍어야 합니다.
3. **콜·발음·출처 채우기.** `cues[]`, `lines[].ko`, `sources[]`(최소 하나)를 채웁니다.
4. **검증.** 오류가 없을 때만 `data/songs/index.json`이 갱신됩니다.
   ```sh
   npm run validate
   ```
5. **타이밍 보정.** 로컬 서버에서 `#/edit/<song-id>`를 열고 타이밍을 맞춘 뒤 JSON을 내려받아 `data/songs/<artist-id>/`에 덮어씁니다. 다시 `npm run validate`를 돌리고 커밋합니다.

## 외부 재생 모드

플레이어가 오류(101/150)를 내면 외부 재생 모드로 바뀝니다. 영상이 재생되는 곡에서도 "외부에서 재생" 버튼으로 고를 수 있습니다(예: 휴대폰에서 음악 앱으로 들을 때).

- **연습 화면:** YouTube 앱이나 다른 탭에서 곡을 틀고, 가사 줄이 시작되는 순간 그 줄을 누르면 사이트 시계가 맞춰집니다. ±0.5초 버튼과 시계 멈춤으로 보정합니다.
- **보정 도구:** 시간이 있는 줄을 고르고 그 줄이 들리는 순간 "선택 항목이 지금 시작"을 누르거나, 곡이 시작될 때 "곡 시작(0초)이 지금"을 누릅니다. 그다음은 Space로 똑같이 기록합니다. ←/→ 조정 후 되감아 다시 재생하는 기능은 동작하지 않습니다.

## 타이밍 보정 도구 조작

| 키 | 동작 |
|---|---|
| Space | 다음 대상(시간 없는 줄 → 시간 미정 콜 → 아직 찍지 않은 줄 기준 콜)에 현재 시간 기록 |
| ← / → | 선택 항목 ±0.1초 (줄 기준 콜은 `offset`), 1초 전부터 다시 재생 |
| Shift + ← / → | ±0.01초 |
| K | 재생 / 일시정지 |
| 1 / 2 / 3 | 재생 속도 0.5배 / 0.75배 / 1배 |

항목을 누르면 그 항목이 다음 대상이 됩니다. 작업 중 상태는 브라우저 `localStorage`에 자동 저장됩니다.
