# 설계 리뷰 결정 원장

## 콜의 `at.line` 첨자 기준(0/1)이 문서끼리 어긋남
- 심각도: [높음]
- 질문 요지: 줄 기준 콜의 `at.line` 을 0부터 셀지 1부터 셀지
- 사용자 결정: 0부터 (첨자)
- 반영 방향: `at.line` 은 0 기준 첨자로 확정한다. design.md(예: 69행 "12번째 줄" 서술)와 specs/song-data/spec.md 의 서수 표현을 "첨자 N(N+1번째 줄)"처럼 0 기준으로 고친다. specs/practice-player/spec.md 의 `lines[line].t + offset` 식은 그대로 유지한다. song-data 범위 검사 시나리오를 0 기준 경계(30줄 곡에서 `line: 30` 은 오류, `line: 29` 는 유효)로 바꾼다. design.md 에 0 기준을 택한 근거(코드 첨자와 일치)와 콘텐츠 입력 시 주의점을 적는다. tasks.md 에 관련 서술이 있으면 함께 맞춘다.
- 상태: 반영완료
- 라운드: 1

## 줄 기준 콜 offset 보정 경로 부재
- 심각도: [높음]
- 질문 요지: Claude 초안 offset 을 보정 도구에서 어떻게 기록·조정할지
- 사용자 결정: 자동 대상에 포함
- 반영 방향: 보정 도구의 "다음 대상" 순서에 줄 기준 콜도 포함한다. 대상이 줄 기준 콜일 때 Space 를 누르면 `offset = 현재 재생 시간 - lines[line].t` 를 기록하고, ←/→ 로 offset 을 조정한다. 해당 줄의 시간이 아직 없으면 그 콜은 줄 시간이 정해진 뒤에 대상이 되도록 순서를 정한다. specs/timing-editor/spec.md 의 대상 정의와 시나리오, design.md Decision 5, tasks.md 5.1/5.2 를 함께 고친다.
- 상태: 반영완료
- 라운드: 1

## 시간 미정 절대 시간 콜의 표현·검증 등급 미정
- 심각도: [높음]
- 질문 요지: 시간을 모르는 절대 시간 콜을 초안에 어떻게 적고 validate 가 어떻게 다룰지
- 사용자 결정: `{t:null}` 허용·경고
- 반영 방향: `at` 형식에 `{ t: null }` 을 시간 미정 절대 콜로 허용한다. validate 는 이를 오류가 아닌 경고("시간이 없는 콜")로 처리해 색인 생성·배포(tasks 7.3)를 막지 않는다. 연습 화면은 시간 미정 콜을 강조·예고 없이 콜 목록에만 표시한다. 보정 도구에서는 시간 미정 절대 콜이 Space 대상이 된다. specs/song-data/spec.md(`at` 정의·경고 목록·시나리오), specs/practice-player/spec.md, design.md Decision 2/7, 관련 tasks 를 함께 고친다.
- 상태: 반영완료
- 라운드: 1
