## Why

원더리벳 2026(2026-11-20~22, 고양 킨텍스, 42팀)은 한국 응원법, 일본 록 콜, 아이돌 콜·MIX가 한 행사에 섞여 있다. 그런데 출연 팀의 응원 자료는 일본어 블로그, 디시 콜표, YouTube 영상 등에 흩어져 있고, 타임스탬프가 붙은 자료는 하나도 없다. 공연까지 10일 남은 지금, 곡을 틀어 놓고 가사·한글 발음·콜을 시간에 맞춰 따라 할 수 있는 개인 연습 사이트를 만든다.

## What Changes

- 빌드 과정이 없는 정적 사이트(HTML + JS + JSON)를 새로 만들고 GitHub Pages에 배포한다.
- 일자별 출연 아티스트와 곡 목록 화면을 만든다.
- 곡별 연습 화면을 만든다. YouTube 영상 재생 시간에 맞춰 현재 가사 줄, 한글 발음, 콜(외치기·박수·점프·떼창·펜라이트 색 등)을 강조한다.
- 타이밍 보정 도구를 만든다. 영상을 재생하며 키를 눌러 가사 줄과 콜의 시간을 기록하고 곡 JSON으로 내보낸다.
- 곡 데이터를 만든다. 대상은 탐색 세션에서 확정한 22팀 56곡이다(`research/final-songs.md`). 기준은 "기존 자료에 곡 단위 응원 정보가 있고, 최근 공연 셋리스트의 40% 이상에서 연주된 곡"이다.
- 동기화 가사는 LRCLIB(lrclib.net)에서 가져오고, 한글 발음은 초안을 만든 뒤 사용자가 검수한다.
- 검색 한도 때문에 조사하지 못한 약 28곡을 재조사해서, 기준을 통과하는 곡은 데이터를 추가한다.

## Capabilities

### New Capabilities
- `song-catalog`: 일자별 출연 아티스트, 아티스트별 곡과 공연 의식(곡에 묶이지 않는 콜)을 찾아보는 화면
- `practice-player`: YouTube 재생과 동기화해 가사·한글 발음·콜을 보여주는 곡별 연습 화면
- `timing-editor`: 재생 중 키 입력으로 가사 줄과 콜의 타임스탬프를 기록하고 JSON으로 내보내는 보정 도구
- `song-data`: 아티스트·곡·가사·콜 데이터의 파일 형식과 검증 규칙, LRCLIB 가져오기

### Modified Capabilities
(없음. 새 저장소다.)

## Impact

- 새 파일: 사이트 소스(`index.html` 등), `data/` 아래 아티스트·곡 JSON, LRCLIB 가져오기 스크립트, 데이터 검증 스크립트, GitHub Pages 배포 설정
- 외부 의존: YouTube IFrame Player API(재생과 시간 조회), LRCLIB API(콘텐츠 준비 단계에서만 호출하고 런타임에는 호출하지 않음)
- 저작권: 가사 전문이 공개 URL에 올라간다. 개인 용도이며 사용자가 이 위험을 감수하기로 결정했다. 저장소도 공개 저장소여야 GitHub Pages를 무료로 쓸 수 있다.
- 일정: 공연 시작(2026-11-20) 전에 연습할 수 있어야 하므로 늦어도 11-17까지 1차 배포가 필요하다.
