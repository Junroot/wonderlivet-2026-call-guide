## ADDED Requirements

### Requirement: 일자별 아티스트 목록
시스템은 첫 화면에 공연 일자(11/20, 11/21, 11/22)별 탭을 보여주어야 한다(SHALL). 각 탭에는 그날 출연하는 아티스트 중 곡 데이터가 하나 이상 있는 아티스트만 공연 시작 시간 순서로 나열해야 한다(SHALL). 항목마다 아티스트 이름(원문과 한글), 스테이지, 공연 시간, 곡 수를 표시해야 한다(SHALL).

#### Scenario: 일자 탭 전환
- **WHEN** 사용자가 첫 화면에서 "11/21" 탭을 누른다
- **THEN** 11/21 출연 아티스트 중 곡 데이터가 있는 아티스트가 공연 시작 시간 순으로 표시된다

#### Scenario: 곡 데이터가 없는 아티스트
- **WHEN** `lineup.json`에는 있지만 `songs/index.json`에 곡이 없는 아티스트가 있다
- **THEN** 그 아티스트는 일자 목록에 표시되지 않는다

#### Scenario: 공연 일자 기본 탭
- **WHEN** 사용자가 첫 화면을 연다
- **THEN** 오늘 날짜와 같거나 그 이후인 가장 가까운 공연 일자 탭이 선택된다. 모든 공연이 끝났으면 첫째 날 탭이 선택된다

### Requirement: 아티스트 화면
시스템은 아티스트 화면에 그 아티스트의 곡 목록과 공연 의식 목록을 보여주어야 한다(SHALL). 곡 항목에는 곡 제목, 포함된 콜 종류, 검수 상태(발음·타이밍)를 표시해야 한다(SHALL). 공연 의식은 곡에 묶이지 않는 콜(예: THE ORAL CIGARETTES의 「4本打ち」)로, 설명과 출처 링크를 보여주어야 한다(SHALL).

#### Scenario: 곡 목록 표시
- **WHEN** 사용자가 일자 목록에서 Roselia를 누른다
- **THEN** `#/artist/roselia` 화면에 Roselia의 곡 제목, 콜 종류 아이콘, 검수 상태가 나열된다

#### Scenario: 공연 의식 표시
- **WHEN** 아티스트 데이터에 공연 의식 항목이 있다
- **THEN** 아티스트 화면의 곡 목록 위에 의식 이름, 설명, 출처 링크가 표시된다

#### Scenario: 검수 전 곡 표시
- **WHEN** 곡의 `review.timing` 또는 `review.pronunciation`이 false다
- **THEN** 곡 항목에 해당하는 "검수 전" 표시가 붙는다

### Requirement: 해시 기반 화면 주소
시스템은 모든 화면을 해시 주소(`#/`, `#/artist/<id>`, `#/song/<id>`, `#/edit/<id>`)로 열 수 있어야 한다(SHALL). 그래서 새로고침하거나 주소를 직접 입력해도 같은 화면이 열려야 한다(SHALL).

#### Scenario: 곡 주소 직접 열기
- **WHEN** 사용자가 `#/song/yuzu-natsuiro` 주소로 사이트를 연다
- **THEN** YUZU 夏色 연습 화면이 바로 열린다

#### Scenario: 없는 주소
- **WHEN** 사용자가 존재하지 않는 곡 id로 `#/song/<id>`를 연다
- **THEN** "곡을 찾을 수 없습니다" 메시지와 첫 화면으로 가는 링크가 표시된다
