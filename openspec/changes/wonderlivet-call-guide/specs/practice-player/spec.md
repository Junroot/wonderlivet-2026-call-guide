## ADDED Requirements

### Requirement: 곡 연습 화면 구성
시스템은 연습 화면에 YouTube 플레이어, 가사 줄 목록, 콜 표시 영역, 출처 링크를 보여주어야 한다(SHALL). 가사 줄마다 원문과 한글 발음(`ko`가 있을 때)을 함께 표시해야 한다(SHALL). 콜은 자신이 붙은 가사 줄 바로 아래에 종류 아이콘, 외칠 문구, 한글 발음, 메모와 함께 표시해야 한다(SHALL).

#### Scenario: 일본어 곡 표시
- **WHEN** 사용자가 `ko`가 채워진 일본어 곡의 연습 화면을 연다
- **THEN** 가사 줄마다 원문 아래에 한글 발음이 표시된다

#### Scenario: 한국어 곡 표시
- **WHEN** 가사 줄의 `ko`가 null이다
- **THEN** 원문만 표시되고 빈 발음 줄은 생기지 않는다

#### Scenario: 펜라이트 색 콜
- **WHEN** 콜 종류가 `penlight`이고 `color` 값이 있다
- **THEN** 콜 아이콘이 해당 색으로 표시된다

### Requirement: 재생 시간 동기화
시스템은 YouTube 재생 시간에 맞춰 현재 가사 줄과 콜을 강조해야 한다(SHALL). 영상 시간은 `가사 시간 + youtube.offsetSec`로 계산해야 한다(SHALL). 가사 줄 기준 콜의 시간은 `lines[line].t + offset`(`line`은 0 기준 첨자), 절대 시간 콜은 `t`를 써야 한다(SHALL). 시간을 계산할 수 없는 콜(`{ t: null }`, 또는 `t`가 null인 줄에 붙은 콜)은 "다음"·"지금" 강조 없이 콜 목록에만 표시해야 한다(SHALL). 강조 오차는 재생 중 0.2초 이내여야 한다(SHALL).

#### Scenario: 현재 가사 줄 강조
- **WHEN** 영상이 재생되어 계산된 가사 시간이 3번째 줄의 `t` 이상이고 4번째 줄의 `t` 미만이다
- **THEN** 3번째 줄이 강조되고, 그 줄이 화면 가운데 근처로 자동 스크롤된다

#### Scenario: 다가오는 콜 예고
- **WHEN** 콜 시간까지 1.5초 이하가 남았다
- **THEN** 콜 표시 영역에 그 콜이 "다음" 상태로 크게 표시된다

#### Scenario: 콜 발동
- **WHEN** 계산된 가사 시간이 콜 시간에 도달한다
- **THEN** 그 콜이 "지금" 상태로 강조되고, 다음 콜 예고로 넘어갈 때까지 유지된다

#### Scenario: 시간 미정 콜
- **WHEN** 콜의 `at`이 `{ "t": null }`이다
- **THEN** 그 콜은 콜 목록에 표시되지만 "다음"·"지금" 상태로 강조되지 않는다

#### Scenario: 일시정지와 탐색
- **WHEN** 사용자가 영상을 일시정지하거나 다른 위치로 탐색한다
- **THEN** 강조 상태가 새 재생 위치 기준으로 즉시 다시 계산된다

### Requirement: 연습 조작
시스템은 가사 줄 클릭으로 탐색, 재생 속도 선택(0.75배, 1배), 한글 발음 표시 켜고 끄기를 제공해야 한다(SHALL). 발음 표시 설정은 다음 방문에도 유지해야 한다(SHALL).

#### Scenario: 가사 줄로 이동
- **WHEN** 사용자가 7번째 가사 줄을 누른다
- **THEN** 영상이 그 줄의 영상 시간으로 이동하고 재생된다

#### Scenario: 느리게 연습
- **WHEN** 사용자가 재생 속도 0.75배를 고른다
- **THEN** 영상이 0.75배로 재생되고, 가사·콜 강조가 같은 속도에 맞춰 진행된다

#### Scenario: 발음 숨기기 유지
- **WHEN** 사용자가 발음 표시를 끄고 다른 곡 화면으로 이동하거나 새로고침한다
- **THEN** 발음은 계속 숨겨진 상태다

### Requirement: 재생 실패 대체
시스템은 YouTube 영상이 임베드 불가 등으로 재생되지 않으면, 가사와 콜을 보여주고 YouTube 원본 링크를 표시해야 한다(SHALL). 이때 외부 재생 모드로 전환해, 사용자가 다른 탭이나 앱에서 곡을 틀고 사이트 자체 시계로 가사·콜 강조를 진행할 수 있어야 한다(SHALL). 영상이 재생되는 곡에서도 사용자가 외부 재생 모드를 직접 고를 수 있어야 한다(SHALL).

#### Scenario: 임베드 차단 영상
- **WHEN** YouTube 플레이어가 오류 코드 101 또는 150을 보고한다
- **THEN** "이 영상은 사이트 안에서 재생할 수 없습니다" 안내와 YouTube 링크가 표시되고, 외부 재생 모드로 전환되며, 가사·콜 목록은 계속 보인다

#### Scenario: 외부 재생 맞추기
- **WHEN** 외부 재생 모드에서 사용자가 외부 재생 중인 곡의 가사 줄이 시작되는 순간 그 줄을 누른다
- **THEN** 사이트 시계가 그 줄의 영상 시간으로 맞춰져 진행되고, 이후 가사·콜 강조가 이 시계를 따른다

#### Scenario: 외부 재생 미세 보정
- **WHEN** 외부 재생 모드에서 사용자가 "+0.5초" 또는 "−0.5초"를 누르거나 일시정지를 누른다
- **THEN** 사이트 시계가 그만큼 이동하거나 멈추고, 강조가 새 시계 기준으로 다시 계산된다
