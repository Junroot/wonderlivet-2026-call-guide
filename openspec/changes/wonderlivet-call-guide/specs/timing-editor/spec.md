## ADDED Requirements

### Requirement: 탭으로 시간 기록
시스템은 보정 화면(`#/edit/<id>`)에서 영상을 재생하며 Space 키로 "다음 대상"에 현재 가사 시간을 기록할 수 있어야 한다(SHALL). 다음 대상은 목록 순서상 다음 중 첫 항목이다(SHALL): 시간이 없는 가사 줄, 시간 미정 절대 시간 콜(`{ t: null }`), 이번 보정 작업에서 아직 기록하지 않은 줄 기준 콜. 목록에서 줄 기준 콜은 자신이 붙은 가사 줄 바로 뒤에 오므로, 줄 시간이 정해진 뒤에 대상이 된다. 가사 줄과 절대 시간 콜에는 `t`를, 줄 기준 콜에는 `offset = 현재 가사 시간 - lines[line].t`를 기록한다. 줄 기준 콜의 기록 여부는 작업 상태에만 두고 곡 JSON에 필드를 추가하지 않는다. 사용자가 항목을 직접 골라 대상을 바꿀 수도 있어야 한다(SHALL). 기록하는 시간은 `영상 시간 - youtube.offsetSec`이다. 영상이 임베드되지 않는 곡은 연습 화면과 같은 외부 재생 모드의 사이트 시계를 영상 시간으로 쓴다(SHALL). 이때 미세 조정 후 다시 재생하는 동작은 하지 않는다.

#### Scenario: 가사 줄 시간 기록
- **WHEN** 다음 대상이 5번째 가사 줄이고 사용자가 영상 시간 48.30초에 Space를 누른다. `offsetSec`는 2.0이다
- **THEN** 5번째 줄의 `t`가 46.30으로 기록되고, 다음 대상이 6번째 줄로 넘어간다

#### Scenario: 줄 기준 콜 offset 기록
- **WHEN** 다음 대상이 `"at": { "line": 4, "offset": 0 }` 콜이고 `lines[4].t`가 46.30, `offsetSec`가 2.0이다. 사용자가 영상 시간 50.10초에 Space를 누른다
- **THEN** 그 콜의 `offset`이 1.80으로 기록되고, 다음 대상이 목록상 다음 항목으로 넘어간다

#### Scenario: 줄 시간보다 먼저 콜을 대상으로 삼지 않음
- **WHEN** `lines[4].t`가 null이고 그 줄에 줄 기준 콜이 붙어 있다
- **THEN** 다음 대상은 먼저 `lines[4]`이고, 그 줄의 `t`가 기록된 뒤에 콜이 대상이 된다

#### Scenario: 시간 미정 절대 시간 콜 기록
- **WHEN** 다음 대상이 `"at": { "t": null }` 콜이고 `offsetSec`가 2.0이다. 사용자가 영상 시간 85.20초에 Space를 누른다
- **THEN** 그 콜의 `at`이 `{ "t": 83.20 }`이 된다

#### Scenario: 대상 직접 선택
- **WHEN** 사용자가 이미 시간이 있는 12번째 줄을 누른 뒤 Space를 누른다
- **THEN** 12번째 줄의 `t`가 현재 시간으로 덮어써진다

### Requirement: 미세 조정과 검증
시스템은 선택한 항목의 시간을 ←/→ 키로 0.1초씩, Shift와 함께 누르면 0.01초씩 조정할 수 있어야 한다(SHALL). 가사 줄과 절대 시간 콜은 `t`를, 줄 기준 콜은 `offset`을 조정한다. 가사 줄 시간이 앞 줄보다 작아지면 해당 줄에 경고를 표시해야 한다(SHALL).

#### Scenario: 0.1초 당기기
- **WHEN** 선택한 줄의 `t`가 46.30이고 사용자가 ←를 누른다
- **THEN** `t`가 46.20이 되고, 영상이 그 줄 시간 1초 전으로 이동해 재생된다

#### Scenario: 줄 기준 콜 offset 조정
- **WHEN** 선택한 줄 기준 콜의 `offset`이 1.80이고 사용자가 →를 누른다
- **THEN** `offset`이 1.90이 된다

#### Scenario: 순서 역전 경고
- **WHEN** 조정 결과 6번째 줄의 `t`가 5번째 줄보다 작아진다
- **THEN** 6번째 줄에 순서 경고가 표시된다

### Requirement: 오프셋 맞추기
시스템은 보정 화면에서 `youtube.offsetSec`를 직접 입력하거나, "첫 가사 줄을 지금으로" 버튼으로 현재 영상 시간과 첫 줄의 `t` 차이를 오프셋으로 정할 수 있어야 한다(SHALL).

#### Scenario: 첫 줄 기준 오프셋
- **WHEN** 첫 줄의 `t`가 12.00이고 사용자가 영상 시간 15.40초에 "첫 가사 줄을 지금으로" 버튼을 누른다
- **THEN** `offsetSec`가 3.40으로 설정된다

### Requirement: 작업 보존과 내보내기
시스템은 보정 중인 곡 데이터를 브라우저 저장소에 자동 저장해야 한다(SHALL). 같은 곡의 보정 화면을 다시 열면 저장된 작업을 이어서 할지 물어야 한다(SHALL). 또 수정된 곡 JSON을 파일로 내려받기와 클립보드 복사로 내보낼 수 있어야 한다(SHALL). 보정 화면은 영상이 로드되면 `player.getDuration()` 값을 `youtube.durationSec`에 기록해야 한다(SHALL). 내보낼 때 "타이밍 검수 완료"를 체크하면 `review.timing`을 true로 설정해야 한다(SHALL).

#### Scenario: 새로고침 후 이어 하기
- **WHEN** 사용자가 보정 중에 페이지를 새로고침한다
- **THEN** 저장된 작업이 있다는 안내와 함께 이어 하기/버리기 선택지가 표시된다

#### Scenario: 검수 완료로 내보내기
- **WHEN** 사용자가 "타이밍 검수 완료"를 체크하고 내려받기를 누른다
- **THEN** `review.timing`이 true인 `<song-id>.json` 파일이 내려받아진다
